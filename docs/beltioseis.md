# Λιστα βελτιωσεων εφαρμογης

Ολα οσα εχουμε πει οτι θελουμε να βελτιωσουμε στην εφαρμογη (ERGODO, το ονομα μπορει να αλλαξει). Καθε γραμμη γραφει ποτε ειπωθηκε και απο που ηρθε. Ο Χρηστος θελει οτι γινεται να φτιαχνεται αμεσως.
