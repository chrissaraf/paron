# Παρουσίαση PARON

Τα εργαλεία παρουσίασης χρησιμοποιούν υποθετική εταιρεία και ξεχωριστή μνήμη. Δεν διαβάζουν τον φάκελο `data/`, δεν δημιουργούν πραγματικούς λογαριασμούς και δεν στέλνουν μηνύματα ή πληρωμές.

- `npm run demo:lan`: παρουσίαση από Mac και κινητό στο ίδιο Wi-Fi. Η κονσόλα εμφανίζει τις διευθύνσεις. Το Mac παραμένει ανοιχτό.
- `Παρουσίαση PARON.command`: εκκίνηση με διπλό κλικ από τον Finder.
- `http://localhost:4175/review`: εναλλαγή προβολής κινητού/Mac και επαναφορά των παραδειγμάτων.
- `node build.js`: αναδημιουργία των σελίδων της εφαρμογής και των `tools/paron-demo.html`, `tools/presentation-guide.html`.
- `paron-demo.html`: εφεδρική παρουσίαση χωρίς server, ανοίγει σε Safari ή Chrome. Η ανανέωση ξεκινά νέο παράδειγμα.

Ο server στο `presentation/server.js` ανοίγει μόνο τις διαδρομές της παρουσίασης. Τα παραδείγματα περιλαμβάνουν χειροκίνητες αναθέσεις, σταθερές ομάδες και πληρωμές στην εβδομάδα που έχει επιλεγεί στην εφαρμογή.
