# PARON Εστίαση

Εφαρμογή προγράμματος βαρδιών, παρουσιών και πληρωμών για εστίαση (σερβιτόροι, βοηθοί, μπαρ, κουζίνα κ.ά.).
Ξεχωριστή από την εφαρμογή εργοταξίων στη ρίζα του αποθετηρίου.

- `index.html`: όλη η εφαρμογή σε ένα αρχείο. Ανοίγει στον browser και κρατά τα δεδομένα τοπικά (localStorage).
