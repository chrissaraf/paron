# ERGODO · Site πώλησης (ergodo.gr)

Το δημόσιο site όπου οι κατασκευαστικές εταιρείες γνωρίζουν το ERGODO και ζητούν συνδρομή.
Είναι ξεχωριστό από την εφαρμογή της εταιρείας (`app.ergodo.gr`) και **δεν ανεβαίνει μαζί της**. Ανεβαίνει μόνο όταν ζητηθεί ρητά το site.

## Αρχεία
- `index.html`: όλο το site σε ένα αρχείο (κείμενα, εμφάνιση, script). Δεν χρειάζεται build.
- `img/`: στιγμιότυπα από την εφαρμογή (από τον φάκελο `screenshots/` του project).

Για να το δεις, άνοιξε το `index.html` στον browser.

## Τι μένει να αποφασιστεί πριν ανέβει
- **Τιμές**: πρόχειρες. Αλλάζουν στα `data-m="29"`, `data-m="59"`, `data-m="119"` των πακέτων και στη συνάρτηση `plan()` του script (για τον υπολογισμό κέρδους). Η ετήσια τιμή βγαίνει αυτόματα ως 10 μήνες.
- **Όρια πακέτων**: έως 10, έως 40, πάνω από 40 άτομα.
- **Προσφορά**: 30 μέρες δωρεάν χωρίς κάρτα, στήσιμο από εμάς στα δύο μεγαλύτερα πακέτα.
- **Φόρμα «Ζητήστε δοκιμή»**: δεν στέλνει ακόμη πουθενά. Πρέπει να συνδεθεί με email ή με τον server πριν ανέβει, και να βγει η δοκιμαστική σημείωση από τις τιμές.
- **Είσοδος πελατών**: δείχνει στο `https://app.ergodo.gr`. Για πολλές εταιρείες χρειάζεται πρώτα διαχωρισμός δεδομένων ανά εταιρεία στον server.

## Ανέβασμα (μόνο όταν ζητηθεί)
Είναι στατικό site. Στον ίδιο VPS με τον Caddy αρκεί:

```
ergodo.gr, www.ergodo.gr {
  root * /var/www/ergodo-site
  file_server
}
```
